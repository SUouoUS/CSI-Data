# CSI-Data

> ESP32 Wi-Fi CSI를 이용한 **침대 점유 / 뒤척임 탐지** 학부 졸업논문 프로젝트

Wi-Fi 신호의 채널 상태 정보(Channel State Information)만으로 침대에 사람이 있는지, 뒤척이고 있는지를 판별할 수 있는지 검증한다. 현재 **파일럿 단계**이며, 본수집에 앞서 실험 조건을 확정하는 것이 목표다.

## 측정 환경

| 항목 | 값 |
|---|---|
| 하드웨어 | ESP32 (chip rev v3.1), TX–RX 2대 |
| 규격 | 802.11n (HT), **40 MHz**, channel 11, secondary channel below |
| STBC | 미사용 |
| CSI 길이 | `len = 384` byte = **192 complex** |
| 블록 구성 | `LLTF` (index 0–63) + `HT-LTF` (index 64–191) |
| 유효 subcarrier | **114개** (HT-LTF, ±2 … ±58) |
| 수신률 | 약 19 Hz |
| 세션 길이 | 5분 |

### CSI 버퍼 해석 (실측 검증 완료)

`len=384`는 두 가지로 해석될 수 있어 실측으로 확정했다.

| 가설 | 구성 | 판정 |
|---|---|---|
| 20 MHz + STBC | LLTF 64 + HT-LTF 64 + STBC-HT-LTF 64 | ❌ |
| **40 MHz, non-STBC** | **LLTF 64 + HT-LTF 128** | ✅ |

HT-LTF 블록(index 64–191)을 128-bin FFT로 풀면 널 패턴이 802.11n HT40 규격과 정확히 일치한다.

```
sc  0        (idx 64)                평균진폭  1.6   → DC null
sc ±1        (idx 65, 191)           평균진폭  5.2   → DC 인접
sc ±2 … ±58  (idx 66–122, 134–190)   평균진폭 30–43  → 유효 (114개)
sc ±59       (idx 123, 133)          평균진폭  5–7   → 전이
sc ±60… ±64  (idx 124–132)           평균진폭  0.6–1.4 → guard
```

> [!IMPORTANT]
> `first_word = 1`이므로 CSI 버퍼의 **첫 4바이트(complex pair 0, 1)는 하드웨어 버그로 무효**다.
> 전 프레임에서 상수값 `47, -16, 2, 0`이 나오며 반드시 마스크에서 제외해야 한다.

## 저장소 구조

```
CSI-Data/
├── csi_core.py            # 파싱 · 전처리 · 특징 · 세션단위 통계 (공통 모듈)
├── sessions.py            # 시나리오 정의 + 세션 매니페스트 + 전역 설정
├── s1_check_format.py     # 무결성 검증  (분석을 시작해도 되는가)
├── s2_session_stats.py    # 세션 단위 비교 (특징이 클래스를 가르는가)
├── s3_subcarrier.py       # subcarrier 스크리닝
├── s5_pilot_check.py      # 파일럿 진단 (본수집 조건 확정용)
├── data/                  # 원시 CSI 로그
├── out/                   # 그림 · CSV 결과물
└── legacy/                # 구버전 (프레임 단위 분석, 참고용 보관)
```

> [!NOTE]
> **파싱과 전처리는 `csi_core.py`에만 존재한다.** 개별 스크립트에 중복 구현하면
> 그림마다 전처리가 갈리므로 금지한다. 새 특징도 `csi_core.py`에 함수로 추가해
> 모든 스크립트가 같은 경로를 타게 한다.

## 분석 파이프라인

각 스크립트는 **"무엇을 판정하는가"** 를 하나씩만 담당한다.

### `s1_check_format.py` — 분석을 시작해도 되는가

세션별로 드롭률·수신률·프레임 간격·RSSI·설정 조합·유효 마스크를 검사하고, 세션 간 일관성을 PASS/FAIL로 판정한다. **FAIL이 하나라도 있으면 종료 코드 1로 멈춘다.**

특히 `규격 유효 subcarrier가 실측 널이 아님` 검사가 실패하면 CSI 블록 구성 가정이 틀렸다는 뜻이므로 이후 어떤 분석도 신뢰할 수 없다.

### `s2_session_stats.py` — 특징이 클래스를 가르는가

비중첩 윈도우로 특징을 뽑고, **세션당 중앙값 1개**를 대표값으로 삼아 세션 단위 정확 순열검정을 수행한다.

| 특징 | 설명 |
|---|---|
| `amp_mean` | 정규화 평균진폭 (스펙트럼 평탄도) |
| `amp_std_time` | subcarrier별 시간 표준편차의 평균 |
| `mad_diff`, `mad_diff_p95` | 프레임간 절대변화량 |
| `pc1_var_ratio` | 제1주성분 분산비 |
| `breath_ratio` | 호흡대역 전력비 (PC1 기반) |
| `breath_snr_max` | subcarrier별 호흡 SNR 최댓값 |
| `breath_n_sub` | 호흡 SNR이 임계 초과인 subcarrier 수 |

### `s3_subcarrier.py` — 어느 subcarrier가 반응하는가

subcarrier별 효과크기를 **세션 간 pooled SD**로 계산하고, BH(FDR) 보정을 적용한다. `완전 분리되는 subcarrier 개수`를 `무작위여도 기대되는 개수`와 나란히 출력해 잡음을 고른 것인지 판단할 수 있게 한다.

### `s5_pilot_check.py` — 본수집 조건을 어떻게 확정할 것인가

호흡 피크의 물리적 타당성 검증, 개별 피험자 이상값의 원인 분해, 대안 특징 탐색을 수행한다.

## 통계 설계 원칙

이 프로젝트가 구버전(`legacy/`)과 갈라지는 지점이다.

| 원칙 | 이유 |
|---|---|
| **독립 표본 단위는 세션** | 한 세션의 수천 프레임은 자기상관 때문에 독립 표본 1개다 |
| **정확 순열검정** (전수) | 표본이 작아 근사 분포를 쓸 수 없다 |
| **도달 가능한 최소 p를 항상 병기** | 표본 수 자체가 부족하면 어떤 특징도 유의할 수 없다 |
| **윈도우 중첩 금지** | 중첩은 표본 수를 인공적으로 부풀린다 |
| **임계값은 `empty`에서만 결정** | 점유 데이터로 정하면 순환논증. 비재실 세션 자신은 leave-one-out |
| **효과크기 분모 = 세션 간 pooled SD** | 세션 내 시간 표준편차로 나누면 Cohen's *d*가 아니다 |
| **BH(FDR) 다중비교 보정** | subcarrier 수백 개를 스크리닝하면 우연히 갈리는 것이 반드시 나온다 |
| **p-hacking 금지** | p값이 안 나오면 그 사실을 결과에 그대로 쓴다 |

### 최소 도달 가능 p

비대응 정확 순열검정에서 표본 수만으로 결정되는 하한이다. 특징을 아무리 잘 골라도 이 값보다 작은 p는 나올 수 없다.

```
n_a == n_b  →  p_min = 2 / C(n_a + n_b, n_a)
n_a != n_b  →  p_min = 1 / C(n_a + n_b, n_a)
```

표본 수가 같을 때는 A와 B를 맞바꾼 배정이 통계량의 부호만 뒤집어 극단값이 **짝으로** 나오지만, 표본 수가 다르면 맞바꾼 배정 자체가 유효하지 않아 관측 배정 하나만 극단일 수 있다.

| 구성 | 최소 p | p < 0.05 |
|---|---|---|
| 3 vs 2 | 0.100 | ❌ |
| 3 vs 3 | 0.100 | ❌ |
| **4 vs 3** | **0.0286** | ✅ |
| 4 vs 4 | 0.0286 | ✅ |
| 7 vs 3 | 0.0083 | ✅ |
| 9 vs 6 | 0.0002 | ✅ |

## 현재까지의 결과

### ✅ 확인된 것

1. **진폭 프로파일은 재실 여부를 반영하지 않는다.** 재실/비재실 세션 간 코사인 유사도가 0.994 – 0.9995로 사실상 동일하며, 상태가 아니라 **배치**가 지배적이다.
2. **`coherence_time`, `effective_rank`, `amp_kurtosis`, `mad_diff`, `pc1_var_ratio`는 재실/비재실을 가르지 못한다.** (sep 0.13 – 0.48)
3. **`breath_snr_max`는 불안정하다.** 분석 창을 280초 → 105초로 바꾸면 피험자 순위가 뒤집힌다.
4. **움직임 vs 정지는 명확히 갈린다.** 세션 내 대조에서 **114 / 114 subcarrier**가 3명 전원 같은 방향으로 반응했고(우연 기대치 25 %), 시간 표준편차가 0.0267 → 0.0363으로 **+36 %** 증가했다.
5. **"subcarrier 간 주파수 일치"로는 호흡을 판별할 수 없다.** `empty1`도 일치율 100 %가 나온다. 인접 subcarrier는 채널 coherence bandwidth 때문에 상관되어 있어 잡음 피크도 함께 움직인다.

### ❓ 가설 (재현 확인 필요)

| | 내용 | 현재 근거 |
|---|---|---|
| **H1** | `P02`의 0.273 Hz(16.4회/분) 피크는 호흡이다 | 전후반 주파수 일치 1회 |
| **H2** | `lowfreq_ratio`(0.01–0.1 Hz)가 재실/비재실을 가른다 | 완전분리, p = 0.0286, sep = 2.81 — **단 BH 보정 후 0.229로 미유의** |
| **H3** | `P01`·`P03`의 낮은 값은 피험자 특성이 아니라 세션 변동이다 | 창 길이에 따른 순위 역전 |

### ❌ 기각된 것

- `stable_5min`의 subcarrier −53…−42 노치가 사람 때문이라는 해석 → P01/P02/P03에는 나타나지 않는다. 해당 세션의 채널 상태였다.
- `P03`에서 호흡이 검출되었다는 해석 → SNR은 최고(14.70)지만 주파수가 0.156 → 0.293 Hz로 변동한다.

### TX / RX 배치

호흡 성분을 안정적으로 얻으려면 **두 기기를 잇는 직선이 가슴 위를 지나야** 한다. 2.4 GHz 기준 제1 프레넬 존 반지름이 약 25 cm이므로, 가슴이 그 선에서 25 cm 안에 들어와야 한다.

```
                침대
        ┌───────────────────────┐
 [TX]───┼──── ● 가슴 정중앙 ────┼───[RX]
        │      (똑바로 누움)     │
        └───────────────────────┘
        ←   2 ~ 3 m (같은 높이)   →
```

- 높이: 매트리스 윗면에서 가슴뼈 표면까지 (보통 20 – 25 cm)
- 벽·금속에서 최소 30 cm 이격
- 위치를 테이프로 표시하고 **12세션 내내 고정**

> [!CAUTION]
> 배치를 바꾸면 **기존 데이터와 같은 조건으로 섞지 않는다.**
> `sessions.py`의 `batch` 필드에 새 라벨을 부여해 별도 파일럿 조건으로 검증한 뒤,
> 본수집에 쓸 배치를 하나로 확정한다.

## 라이선스 / 데이터 취급

참가자로부터 수집한 측정 데이터를 포함하므로 **비공개 저장소로 유지한다.**
피험자는 `P01` · `P02` · `P03`으로 익명화되어 있으며, 로그에는 개인 식별 정보가 포함되지 않는다.
