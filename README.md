# CSI-Data

> ESP32 Wi-Fi CSI를 이용한 **침대 점유 / 뒤척임 탐지** 학부 졸업논문 프로젝트

Wi-Fi 채널 상태 정보(CSI)만으로 침대에 사람이 있는지, 뒤척이고 있는지 판별할 수 있는지 검증한다.
현재 **파일럿 단계**이며, 본수집에 앞서 실험 조건을 확정하는 것이 목표다.

---

## 측정 환경

ESP32 2대(TX–RX), 802.11n **40 MHz**, channel 11, 약 **19 Hz**, 세션당 **5분**.

CSI 한 프레임은 `len = 384` byte = 192 complex이며, 실측 널 패턴으로 **LLTF(64) + HT-LTF(128)** 구성임을 확정했다. 분석에는 HT-LTF의 유효 subcarrier **114개**(±2 … ±58)만 사용한다.

<details>
<summary>블록 구성 판정 근거</summary>

`len=384`는 `20 MHz + STBC`(64×3)로도, `40 MHz + non-STBC`(64+128)로도 해석된다.
메타데이터가 `bandwidth=1`, `stbc=0`이고, index 64–191을 128-bin FFT로 풀었을 때
널 패턴이 802.11n HT40 규격과 정확히 일치하므로 후자로 확정했다.

```
sc  0        (idx 64)              1.6      → DC null
sc ±2 … ±58  (idx 66–122,134–190)  30–43    → 유효 (114개)
sc ±60… ±64  (idx 124–132)         0.6–1.4  → guard
```

또한 `first_word = 1`이므로 버퍼의 **첫 4바이트는 하드웨어 버그로 무효**다.
전 프레임 상수값 `47, -16, 2, 0`이 나오며 마스크에서 제외한다.

</details>

## 데이터

파일럿 **10세션**. 상태 라벨은 `still` / `empty` / `motion` 셋이다.

| 파일 | 구성 | 비고 |
|---|---|---|
| `P01_stable` `P02_stable` `P03_stable` | still 5분 | 피험자 3명 |
| `P01_motion` `P02_motion` `P03_motion` | still 2분 → **motion 1분** → still 2분 | 15초 간격 동작 4회 |
| `empty1` `empty2` | empty 5분 | |
| `stable_5min` `empty_5min` | still / empty 5분 | 선행 수집 |

> [!WARNING]
> 선행 수집 2개(배치 A)는 나머지 8개(배치 B)와 캡처 조건이 다르다.
> 수신률 17.5–18.1 Hz vs 19.1–19.4 Hz, id 손실 **7.7–10.7 %** vs **1.1–2.7 %**.
> 섞어 쓰면 배치 효과가 라벨 효과로 오인될 수 있다.

## 통계 설계

구버전(`legacy/`)과 갈라지는 핵심 지점이다.

- **독립 표본의 단위는 프레임이 아니라 세션이다.** 한 세션의 수천 프레임은 자기상관 때문에 표본 1개다.
- **정확 순열검정**을 쓰고, 표본 수만으로 결정되는 **도달 가능한 최소 p를 항상 함께 출력**한다. 그 값이 0.05보다 크면 어떤 특징을 써도 유의할 수 없다.
- **임계값은 `empty` 세션에서만** 정한다. 점유 데이터로 정하면 순환논증이다.
- 효과크기 분모는 **세션 간 pooled SD**, subcarrier 스크리닝에는 **BH(FDR) 보정**을 적용한다.
- 윈도우 중첩 금지, **p-hacking 금지.** p값이 안 나오면 그 사실을 결과에 그대로 쓴다.

## 결과

### ✅ 확인

- **움직임은 뚜렷하게 검출된다.** 세션 내 대조에서 **114 / 114 subcarrier**가 피험자 3명 전원 같은 방향으로 반응했고(우연 기대치 25 %), 시간 표준편차가 **+36 %** 증가했다.
- **정적 재실/비재실은 갈리지 않는다.** 진폭 프로파일은 상태와 무관하게 코사인 유사도 0.994–0.9995로 동일하고, 시도한 특징 8개가 모두 sep < 1.4로 기준(≥ 2)에 미달했다.

### ❓ 가설 — 재현 확인 필요

- `P02`의 0.273 Hz(16.4회/분) 피크는 호흡일 수 있다. 근거는 전후반 주파수 일치 **1회**뿐이다.
- `lowfreq_ratio`(0.01–0.1 Hz)가 완전 분리를 보였으나(p = 0.0286), **BH 보정 후 0.229로 미유의**다.

### ❌ 기각

- `stable_5min`의 깊은 노치가 사람 때문이라는 해석 → 피험자 3명에게는 나타나지 않는다.
- `P03`에서 호흡이 검출되었다는 해석 → SNR은 최고지만 주파수가 0.156 → 0.293 Hz로 변동한다.

## 실행

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install numpy scipy matplotlib
```

```bash
python s1_check_format.py     # 반드시 먼저. FAIL이면 여기서 멈춘다
python s2_session_stats.py
python s3_subcarrier.py
python s5_pilot_check.py
```

```python
{"name": "b2_01_P02", "scenario": "S-1", "file": "b2_01_P02_stable.txt",
 "subject": "P02", "batch": "B2", "segments": [("still", 0.0, 299.0)]},
```
